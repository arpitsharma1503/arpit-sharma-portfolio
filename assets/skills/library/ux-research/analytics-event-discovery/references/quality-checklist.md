# Quality checklist

- [ ] Scope, sources and versions are explicit; only sources actually accessed are listed.
- [ ] Findings trace to evidence; facts, interpretation and recommendations are kept apart.
- [ ] Missing inputs and assumptions are visible.
- [ ] No record, metric, quote, link, tool access or completed action is invented.
- [ ] Changes were applied only with approval, and failures or partial coverage are reported.
- [ ] Privacy, security, permissions and human review needs are addressed.
