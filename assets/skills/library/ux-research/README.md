# UX Research skills

| Skill | What it does |
|---|---|
| `feature-request-insights` | Turns raw customer feature requests into patterns, friction points and prioritised needs. |
| `evidence-based-personas` | Builds personas from real research and customer evidence, never from assumptions. |
| `research-repository-search` | Searches every connected research source and returns cited answers to a research question. |
| `analytics-event-discovery` | Finds the analytics events a feature already tracks, reads trends and fills the gaps. |
| `participant-recruitment` | Finds, screens and schedules the right participants for a study. |

Install: copy the skill folders you want into `~/.claude/skills/` (Claude Code), or upload a single skill's zip in the Claude app.
