# UX Writing skills

| Skill | What it does |
|---|---|
| `ux-copy-first-drafts` | Writes first drafts of UI copy with before/after examples and reasons. |
| `plain-language-review` | Flags hard sentences and jargon in UI copy and suggests clearer words. |
| `terminology-reviewer` | Finds inconsistent terms across the codebase and proposes bulk fixes. |
| `ux-writing-code-review` | Reviews UI strings in pull requests for voice, tone and terminology. |
| `ux-writing-prd-insights` | Reads a PRD from a content angle and sets the terms a feature should use. |
| `product-email-review` | Reviews customer emails for voice, tone and content guidelines. |
| `enrich-writing-guidelines` | Strengthens UX writing guidelines with patterns from the product and competitors. |

Install: copy the skill folders you want into `~/.claude/skills/` (Claude Code), or upload a single skill's zip in the Claude app.
