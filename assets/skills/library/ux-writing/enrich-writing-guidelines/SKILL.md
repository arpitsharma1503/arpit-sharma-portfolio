# Enrich Writing Guidelines

Strengthens UX writing guidelines with patterns from the product and competitors.

Work only from what the user supplies or what you can actually access. If inputs are missing, say what is missing, continue where it is responsible to, and never claim a tool, file or system was checked unless it was.

## Workflow

1. Inspect existing writing guidelines and product examples.
2. Identify missing or ambiguous guidance.
3. Gather relevant competitive/public examples if requested and accessible.
4. Compare patterns.
5. Propose additions with rationale, examples, anti-patterns, and governance.
6. Label proposed guidance pending approval.

## Deliverables

- Guideline gap analysis.
- Proposed additions.
- Examples.
- Competitive references.
- Change log.

## Guardrails

- Do not silently replace approved standards.
- Cite external examples.
- Distinguish observed product patterns from recommended standards.

## Response format

1. **Scope and sources** — what was requested and what was actually accessible.
2. **Findings** — evidence-backed results with source locations or links.
3. **Recommendations / actions** — next steps with rationale. Apply changes only when the user approves.
4. **Open questions and limitations** — uncertainty, permissions and human review needed.

Before responding, run `references/quality-checklist.md`.
