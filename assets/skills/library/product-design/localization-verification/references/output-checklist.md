# Output checklist

- [ ] Scope and sources are explicit; only sources actually accessed are listed.
- [ ] Missing inputs and assumptions are visible.
- [ ] Every factual claim traces to a supplied source or cited reference.
- [ ] Evidence, interpretation, hypothesis and recommendation are kept apart.
- [ ] No tool use, file access, screenshot, metric or validation is claimed unless it actually happened.
- [ ] Uncertainty and contradictions are preserved.
- [ ] Limitations and required human review are stated.
