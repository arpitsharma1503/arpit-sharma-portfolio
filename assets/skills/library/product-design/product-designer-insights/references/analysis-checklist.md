# Analysis checklist

## Before synthesis
- [ ] Every relevant source and version is in the source register.
- [ ] Product/feature scope is confirmed.
- [ ] Missing dates, sample details, metric definitions and context are recorded.
- [ ] Requirements are kept separate from evidence about user behaviour.

## During synthesis
- [ ] Evidence is clustered without erasing meaningful differences.
- [ ] Contradictory signals are preserved.
- [ ] Evidence, findings, interpretations and hypotheses are labelled.
- [ ] Each confidence level has a rationale.
- [ ] Findings trace to source IDs and locators.
- [ ] No unsupported personas, journeys, metrics or quotes.

## Before responding
- [ ] Every factual claim is traceable; quotes and metrics are exact.
- [ ] Contradictions and missing data are visible.
- [ ] Problem statements don't prescribe a solution.
- [ ] Opportunities and recommendations connect to evidenced findings, with rationale and validation needs.
- [ ] Open questions and limitations are explicit.
- [ ] Nothing implies a concept was tested or validated when it wasn't.
