# Product Designer Insights

A Claude skill that turns PRDs, research and customer feedback into traceable, evidence-backed design insights.

## Install

- **Claude Code:** copy this folder to `~/.claude/skills/product-designer-insights/` (personal) or `.claude/skills/product-designer-insights/` (one project).
- **Claude app:** upload the zip of this folder in Settings › Skills.

The folder must contain `SKILL.md`, `references/` and `examples/`.

## Use

Give Claude a PRD, research notes, customer feedback or an analytics summary, and ask, for example:

> Use Product Designer Insights to review this PRD and the attached interview notes. Do a full synthesis and flag unsupported assumptions.

Modes: quick scan, full synthesis, PRD review, research synthesis, design brief, workshop prep.
