# Product Design skills

| Skill | What it does |
|---|---|
| `product-designer-insights` | Turns PRDs, research and feedback into traceable design insights, each linked to its source. |
| `design-system-pattern-finder` | Finds the existing patterns and components that fit a requirement, before anyone designs something new. |
| `automated-usability-studies` | Walks through tasks against heuristics and requirements to catch issues early. A simulated audit, not user research. |
| `pattern-inspiration` | Curates real UI examples for a design problem and turns them into principles, not copies. |
| `competitive-analysis` | Benchmarks competitors' workflows from public sources, with every claim dated and cited. |
| `ai-workflow-generator` | Turns a standard workflow into an AI-agent workflow with clear roles, approvals and recovery paths. |
| `whiteboard-to-mockup` | Turns sketches and whiteboard photos into a journey map and screen specs ready for Figma. |
| `localization-verification` | Checks strings and screens across languages for terminology, layout breaks and locale formats. |
| `edge-case-and-accessibility-audit` | Finds missing states, edge cases, error handling and accessibility gaps before they ship. |

Install: copy the skill folders you want into `~/.claude/skills/` (Claude Code), or upload a single skill's zip in the Claude app.
