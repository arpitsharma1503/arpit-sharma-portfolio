# PRD Assistant

Drafts a Product Requirements Document one phase at a time, never invents content, and writes the PRD to Confluence.

Install: copy this folder to `~/.claude/skills/prd-assistant/` (Claude Code), or upload its zip in the Claude app's skill settings.
Use: ask Claude to "Draft a PRD for …" or type `/prd-assistant`. Connect Confluence to get the PRD as a new page.
