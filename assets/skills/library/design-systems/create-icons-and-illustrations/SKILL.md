# Create Icons & Illustrations

Creates icon and illustration concepts that match the creative guidelines and existing library.

Work only from what the user supplies or what you can actually access. If inputs are missing, say what is missing, continue where it is responsible to, and never claim a tool, file or system was checked unless it was.

## Workflow

1. Clarify purpose, context, size, style, state, and platform.
2. Inspect approved guidelines and existing assets.
3. Identify reuse opportunities.
4. Write a visual brief and variants.
5. Create assets only with an available image/vector tool.
6. Validate consistency, legibility, accessibility, and export formats.
7. Document handoff.

## Deliverables

- Creative brief.
- Reuse assessment.
- Asset variants if generated.
- Export specification.
- Usage guidance.

## Guardrails

- Do not claim generated vector/source assets if only raster output exists.
- Do not imitate unlicensed third-party artwork.
- Follow brand and accessibility guidelines.

## Response format

1. **Scope and sources** — what was requested and what was actually accessible.
2. **Findings** — evidence-backed results with source locations or links.
3. **Recommendations / actions** — next steps with rationale. Apply changes only when the user approves.
4. **Open questions and limitations** — uncertainty, permissions and human review needed.

Before responding, run `references/quality-checklist.md`.
