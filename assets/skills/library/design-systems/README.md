# Design Systems skills

| Skill | What it does |
|---|---|
| `visual-review` | Finds broken components, missing tokens, style overrides and spacing issues, then suggests fixes. |
| `design-system-guidelines` | Checks a proposed UI follows the design system's layouts, patterns and conventions. |
| `figma-to-code-checker` | Compares the built UI with the approved Figma file and lists every difference to fix. |
| `create-new-components` | Drafts new components from existing patterns, with variants, states and usage notes. |
| `create-icons-and-illustrations` | Creates icon and illustration concepts that match the creative guidelines and existing library. |
| `rename-frames` | Renames Figma frames clearly and consistently, based on what each frame contains. |
| `swap-archived-components` | Moves a file from an archived library to the current one, keeping content and overrides. |
| `comments-to-task-list` | Turns Figma comments and sticky notes into a clear task list on the canvas. |
| `token-handoff` | Hands design-token changes to engineering with names, values, docs and status. |
| `icon-handoff` | Runs icon handoff end to end and tracks it until engineering confirms. |
| `illustration-handoff` | Runs illustration handoff end to end and tracks it until engineering confirms. |
| `log-design-requests` | Collects design-team requests from every channel into one log, so nothing gets lost. |
| `track-open-tickets` | Tracks the team's open tickets and surfaces what's blocked, overdue or needs attention. |

Install: copy the skill folders you want into `~/.claude/skills/` (Claude Code), or upload a single skill's zip in the Claude app.
